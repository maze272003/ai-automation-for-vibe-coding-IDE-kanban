## Task 1 — Contracts

Files: `packages/contracts/src/files.ts` (new), `packages/contracts/src/index.ts`,
`packages/contracts/src/common.ts`.

- Add `FILE_CHANGED` to `ERROR_CODES`.

- Export the caps (`MAX_FILE_BYTES`, `MAX_TREE_ENTRIES`, `MAX_SEARCH_RESULTS`,

- `RepoRelPath` checks: empty, length > 2000, C0/C1 controls and bidi overrides, absolute `/`,

`con.txt`, `a|b`; cap enforcement on content; DTO round-trips; strict write body.

## Task 2 — Service path helpers + tree

Files: `apps/orchestrator/src/files/service.ts` (new).

- `WorkspaceFileService` deps `{ projects: ProjectService; busy?: (id: number) => string | null }`.
- Private `project(id)`, `root(project)` (realpath, missing → 409 `NOT_IN_WORKING_TREE`),
  `normalize(rel)` (re-run `RepoRelPath`), `resolveExisting(project, rel)`,
  `resolveParent(project, rel)`.
- `tree(projectId, rel = '')` as §6.1. Use `fs.promises.readdir(..., { withFileTypes: true })`,
  skip `.git` and `.aik-*.tmp`, sort dirs/files/symlinks then
  `localeCompare(..., undefined, { sensitivity: 'base' })` with a case-sensitive tie-break.
- Cap 1,000 rows; set `truncated` when more rows existed. Hide entries whose names are not
  representable as safe repo-relative paths.
- Symlinks: `type: 'symlink'`, `size: null`.
- Return normalized `path` ('' for root).

Suggested structure:

```ts
export class WorkspaceFileService {
  constructor(private readonly deps: { projects: ProjectService; busy?: (id: number) => string | null }) {}
  async tree(projectId: number, rel = ''): Promise<FileTreeDTO> { ... }
  async read(projectId: number, rel: string): Promise<FileContentDTO> { ... }
  async search(projectId: number, query: string, opts?: { caseSensitive?: boolean; limit?: number }): Promise<FileSearchDTO> { ... }
  async write(projectId: number, body: FileWriteRequest): Promise<FileWriteDTO> { ... }
}
```

Tests (`apps/orchestrator/test/files-service.test.ts`): setup mirrors `view-service.test.ts`
with `createTestDb`, `makeTempRepo`, `ProjectService.create`, temp cleanup in `afterEach`;
also `assertInTemp(repo)` at setup. Cover every tree case in §11.

Verify: `npx vitest run apps/orchestrator/test/files-service.test.ts`.

   disabled Save; reload through the dialog recovers.
4. Binary/truncated files: create `bin.dat` with NULs and a >2 MiB file; opening them shows the

## Task 3 — `TerminalManager` (desktop main, electron-free)

Files: `apps/desktop/src/main/terminal.ts` (new), `apps/desktop/test/terminal.test.ts` (new).

- Implement per spec §Component design 2: deps `{ createPty?, schedule?, killTree?,
  send }`; `PtyLike` interface; sessions keyed by monotonic id storing
  `{ pty, ownerId, ownerOff, cwd, pid, buffer }`; `open(payload, owner)` with cwd
  validation (existing directory via `fs.promises.stat`, absent → `os.homedir()`),
  cap enforcement, `%COMSPEC%` fallback `cmd.exe`, `env: process.env`,
  `name: 'xterm-256color'`; owner lifetime hooks (`did-start-navigation`,
  `render-process-gone`, `destroyed`) kill that owner's sessions; coalesced output
  flush through `schedule`; `onExit` flush + event + delete; `write`/`resize`/
  `close` with try/catch; `close` = `pty.kill()` + `killTree(pid)` + delete;
  idempotent `killAll()`. Top-level `import { spawn } from 'node-pty'` (external in
  the bundle; loads under vitest — probe-verified). Never logs.
- Default `killTree`: `spawnSync('taskkill', ['/PID', String(pid), '/T', '/F'])`
  on win32, swallowed errors, no-op otherwise (spec T-9).
- Tests (fake pty factory recording calls and emitting data/exit; fake `send`
  capturing events; manual flush via injected `schedule` that queues callbacks;
  fake owner as a plain `EventEmitter`):
  1. open → `{ok:true,id:1,cwd}`; pty spawned with cwd/cols/rows/env; second open → id 2.
  2. cwd validation: temp dir passes (assert path under OS temp); missing dir →
     `INVALID_CWD`; file (not dir) → `INVALID_CWD`; absent cwd → homedir.
  3. cap: 9th open → `TOO_MANY_SESSIONS`.
  4. write/resize route to the right session; unknown id → `false`; throwing pty
     (resize throws like a post-exit race) → `false`, no unhandled rejection.
  5. output coalescing: two `onData` chunks → one flushed `aik:terminal-data` with
     concatenated data, in order; flush-on-exit delivers the tail before
     `aik:terminal-exit`.
  6. exit event → session deleted; later write → `false`; late second exit ignored.
  7. close → `pty.kill()` + `killTree(pid)` called with the session pid; delete.
  8. killAll → kills every session exactly once; second killAll no-ops; nothing sent.
  9. owner lifetime: owner emits `did-start-navigation` / `render-process-gone` /
     `destroyed` → only that owner's sessions killed, other owner untouched; owner
     hooks unsubscribed after killAll (no listener leak).
  10. send is never called after the manager dropped a session (exit/closed).
- Verify: `npx vitest run apps/desktop/test/terminal.test.ts`, `npm run typecheck`,
  `npm run lint`.
- Commit: `feat(desktop): TerminalManager — capped ConPTY sessions with owner lifetime and tree-kill (IDE-5)`

  (spec §Component design 3): four `ipcMain.handle` channels; untrusted sender →

  trusted-sender arrow (`index.ts:128`/`:156`) into one `const isTrustedSender = …`
  used by bridge/office/terminal registrations (behavior-identical).
- No unit tests for this file (thin + electron-importing; office-view precedent).
  The manager-level behavior is covered by Task 3; the IPC path by Task 7.
- Verify: `npm run typecheck`, `npm run lint`, `npx vitest run apps/desktop/test`,

## Task 3 — DiagnosticsService extensions

Files: `apps/orchestrator/src/maintenance/diagnostics.ts`,
`apps/orchestrator/test/diagnostics-service.test.ts` (new).

Constructor (keep existing callers working):

```ts
export interface DiagnosticsDeps {
  db: AikDb;
  logsDir?: string;
  backupsDir?: string;
  version?: string;
  electronVersion?: string | null;
  redactor?: Redactor;
  extraComponents?: () => Partial<Pick<DiagnosticsHealthComponents,
    'opencode' | 'gateway' | 'github' | 'ollama'>>;
}
```

- Import `DIAGNOSTICS_*`, `DiagnosticsLogFileDTO`, `DiagnosticsErrorDTO`,
  `DiagnosticsHealthDTO`, `DiagnosticsBackupDTO` from `@aik/contracts`.
- **Log name + containment helper.** Strict regex from contracts, then:
  - `readdirSync(logsDir, { withFileTypes: true })`; only `entry.isFile()` and regex
    matches.
  - `lstatSync(full)` must be a regular file (rejects symlink/junction entries).
  - `realpathSync(logsDir)` and `realpathSync(full)`; require the target to equal
    `path.join(realRoot, name)` (case-insensitive on win32) so a link cannot escape.
  - `listLogs()` returns newest-first `{name,size,modifiedAt}` (ISO), `[]` when the dir
    is missing/unreadable.
- **`readLog(name, tailBytes)`**: repeat the containment checks, `openSync(full,'r')`,
  `fstatSync(fd)` must be a regular file, read only `max(0,size-tailBytes)` with
  `readSync`, close in `finally`. Decode UTF-8. When truncated, drop everything before
  the first `\n`; set `truncated: true`. Redact, then `scanText` fail-closed (throw if
  hits). Return `null` for unknown/unreadable; include `size`, `modifiedAt`,
  `redacted: true`.
- **`recentErrors(limit)`**: for each listed log, read the max tail through the safe
  reader; parse JSON lines only; accept numeric pino `level >= 40` or string
  `warn|error|fatal`; `time` from ISO string or epoch millis, else null; `message` from
  `msg`/`message`; `detail` from `err.stack`/`err.message`, capped (message 500, detail
  2000 chars). Redact each; drop entries where `scanText` hits. Sort newest-first with
  null times last; cap at `limit`; report `scannedFiles`.
- **`health()`**: overall `ok` only when every component is `ok`; `degraded` otherwise.
  - `db`: `SELECT 1`; size from `page_count * page_size` pragmas (guard casts and
    failures; fall back to `0` and `degraded`).
  - `logs`: configured/readable + file count.
  - `backups`: configured/readable + count + latest DTO.
  - `opencode`, `gateway`, `github`, `ollama`: merged from `extraComponents()` or
    `{status:'unavailable',detail:'not configured'}`.
  - `uptimeSeconds`, `memory.rssBytes`, `memory.heapUsedBytes`, versions
    `{app,node,electron}`.
- **`listBackups()`**: `backupsDir` entries matching `/^app-.*\.db$/`, regular files,
  newest-first `{name,size,modifiedAt}`, `[]` when missing/unreadable.
- **`createBackup(now = new Date())`**: single-flight (`private backupInFlight`) and
  10 s throttle. `mkdirSync(backupsDir,{recursive:true})`; `VACUUM INTO '…'` using the
  existing escaping pattern from `packages/db/src/open.ts`; `pruneBackups` to
  `DIAGNOSTICS_MAX_BACKUPS`; return `{ok:true,name,size}`. Never throw: map failures to
  fixed reasons (`'backups unavailable'`, `'throttled'`, `'backup failed'`); never leak
  paths.
- **`exportArchive()`**: keep the existing JSON shape fields (`version`, `timestamp`,
  `diagnostics.{platform,projects,providers,logs}`) and add
  `diagnostics.database: {sizeBytes,pageCount,pageSize}`. Use the safe tail reader for
  logs, cap to the newest 20 files and 2 MiB total across files, redact then run the
  final `scanText` fail-closed. Do not read whole files.
- Tests: temp dirs only (`helpers/temp.ts`); rotation names; tail truncation + first-line
  drop; UTF-8 boundary; unknown/invalid name → null; symlink (skip if Windows cannot
  create one, `test.skipIf`) escape rejected; token/AWS-key redaction; fail-closed scan;
  error levels, ordering, limit, malformed/stdio lines; health shape with all seven
  components; backup create/list/prune, throttle, single-flight, failure reason; export
  shape + DB stats + caps.

Acceptance: `npx vitest run apps/orchestrator/test/diagnostics-service.test.ts` green;
existing `retention-diagnostics.test.ts` green.

## Risks and mitigations

| Risk | Mitigation |
|---|---|
| `system` theme changes the default appearance | Default stays `dark`; only an explicit user choice follows the OS. |
| Global shortcuts steal typing | Editability + `[role="dialog"]` guards for every binding including F1; unit tests cover targets. |
| Log content leaks a secret | Service-boundary redaction + fail-closed scan; allow-list + symlink/realpath containment; tests with fake tokens/AWS keys. |
| Symlink/junction escape | `lstat` + `realpath` containment + post-open `fstat`; test skips only where the OS forbids symlink creation. |
| Huge log files block the event loop | Tail reads only (≤256 KiB) with `readSync`; export caps 20 files / 2 MiB; error scan bounded. |
| Backup loop DoS | Single-flight + 10 s throttle + prune to 5; fixed reasons. |
| Export archive too large for IPC | Export happens in main; renderer only receives `{ok,path}`. |
| Renderer can fetch the archive directly | Bridge path allow-list denies `/diagnostics/export` after normalization; e2e/unit tests cover encoded and dot-segment bypasses. |
| Live restore corrupts state | Restore remains startup-failure-only; UI shows the note; parent amendment recorded. |
| Backup during writes | `VACUUM INTO` produces a consistent snapshot; errors return a reason. |
| Route conflicts with `/diagnostics/export` | Fastify static route precedence + route tests for both. |

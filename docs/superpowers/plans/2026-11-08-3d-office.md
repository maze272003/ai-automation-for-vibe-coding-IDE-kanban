# 3D Agent Office Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the embedded Pixel Agents office with a native 3D headquarters in the desktop app where every project gets its own suite (development room + connected QA lab), agents appear as pixel-art characters that walk to activity spots, and everything is customizable.

**Architecture:** The orchestrator owns room identity and slot assignment (new `office_rooms` table, `OfficeRoomService`, `/office/*` routes) and adds `check.*` outbox events from the verifier. The renderer (`apps/ui/src/office3d/`) keeps all logic in pure, unit-tested TypeScript modules (layout, view-model, behaviour, voxel meshing) and renders through a thin React Three Fiber layer. Pixel Agents is removed last.

**Tech Stack:** TypeScript 6, React 19.3.1, TanStack Router, `three@0.186.1`, `@react-three/fiber@9.8.2`, `@types/three@0.186.0` (no drei), Fastify, Drizzle + better-sqlite3, Zod 4, Vitest 5 (node env), Playwright.

**Spec:** `docs/superpowers/specs/2026-11-08-3d-office-design.md` — read it before any task; section numbers below (§) refer to it.

## Global Constraints

- Dependencies use exact versions only (`npm install -E`); `npm run check:pins` must pass.
- Before claiming any task done: `npm run check:pins && npm run lint && npm run typecheck && npm test`.
- Tests never touch a real repository: use `apps/orchestrator/test/helpers/temp.ts` (`makeTempDir`, `makeTempRepo`) and `helpers/db.ts` (`createTestDb`).
- Story status changes only through `WorkflowService`. The office never changes story status.
- Never log or persist secrets; any persisted process output goes through the redactor (`this.redact`).
- Never import from `spikes/`.
- Desktop app only; everything bundled locally; production CSP is `img-src 'self' data:; connect-src 'self'; worker-src 'self' blob:` and no WASM — use `CanvasTexture` from in-memory canvases only, never `blob:` URLs.
- Vitest runs with `environment: 'node'`; there is no React component-test setup. Renderer logic goes in pure modules under `apps/ui/src/office3d/{layout,state,voxel,sprites,screens}` with tests in `apps/ui/test/office3d/*.test.ts`. The R3F layer (`scene/`, `ui/`) has no unit tests; E2E covers it.
- Units: 1 scene unit = 1 m. Editor grid 0.25 m. Rotations in degrees, multiples of 15.
- Dimensions (§6.2): hub 36 × 36; hallway width 5; slot 22 (along hallway) × 12 (depth); dev room 14; QA lab 8; interior height 3.5.
- Status colours (defaults, §6.5): idle `#94a3b8`, planning `#60a5fa`, working `#f59e0b`, reviewing `#a78bfa`, testing `#22d3ee`, completed `#4ade80`, error `#f87171`. Role shirt colours: planner `#60a5fa`, implementer `#f59e0b`, reviewer `#a78bfa`, qa `#22d3ee`, pm `#4ade80`.
- Behaviour timings (§6.5a, §6.4a): move after activity lasted 3000 ms; min dwell 4000 ms; idle → coffee after 8000 ms with no event; failure at whiteboard ≥ 5000 ms; "completed" shown 60000 ms; bubble text ≤ 40 chars (truncate with `…`).
- Commit after each task with a conventional message ending in the repo's attribution lines.

## Review Focus

1. **Duplicate repo path casing on Windows** — re-importing `C:\Repos\Alpha` as `c:/repos/alpha/` must re-attach the same room, never create a second one. Test owned by Task 3 (`normalizeRepoPath` + restore test).
2. **Project deleted while its room is open in the office** — the room must turn archived live (via `office.rooms_changed`), not crash or keep showing agents. Test owned by Task 3 (event emitted on delete) and Task 11 (reducer drops figures of archived rooms).
3. **Burst of tool events (dozens per second)** — figures must not jitter between couch and desk; only the bubble updates. Test owned by Task 12 (anti-jitter).
4. **Room editor producing an unreachable spot** (couch boxed in by desks) — save must be refused, never leave agents unable to walk. Test owned by Task 9 (validation rejects layouts whose waypoint graph is disconnected — uses Task 10's `isConnected`).
5. **Old `settings.json` from before this feature** (has `agentOffice`, no `office3d`) — app must start with default office preferences, and saving settings must not drop `opencodeMode`. Test owned by Task 7 and Task 22.

  - `class OfficeRoomService { constructor(deps: { db: AikDb; bus: EventBus; now?: Clock }) }` with:
    - `onProjectCreated(project: { id: number; key: string; name: string; repoPath: string }): OfficeRoomDTO` — restore by `repoPathNorm` or create; keeps old slot if still free, else first free `slotAt(n)`.
    - `onProjectDeleted(projectId: number): void` — state `archived`, `projectId = null`, `archivedAt = now`, slot kept, snapshots kept.
    - `reconcile(): void` — every non-archived project without an active room gets one (ordered by project `createdAt`); every active room whose `projectId` no longer exists is archived. Emits one event if anything changed.
    - `list(opts: { includeArchived: boolean }): OfficeRoomDTO[]` — joins current project name/key/status; ordered by slot fill order (archived without slot last).
    - `patch(id: number, req: PatchOfficeRoomRequest): OfficeRoomDTO` — 404 `NOT_FOUND` if missing.
    - `compact(): OfficeRoomDTO[]` — active rooms re-slotted to `slotAt(0..n-1)` in current fill order; archived rooms' slots set to null; single transaction.
    - `deleteArchived(id: number): { ok: true }` — 409 `VALIDATION_FAILED` "Only archived rooms can be deleted" when active.
  - Every mutating method appends outbox `{ topic: 'office.rooms_changed', storyId: null, provenance: 'system', data: { roomIds: number[] } }` inside its write and calls `bus.notify(seq)` after.
  - Default customization: `{ signName: null, accentColor: defaultAccent(key), icon: null, screens: null, layout: null }`.
